졸업논문 참고논문을 자동으로 요약하는 작업이다. 모든 보고는 한국어 존댓말로, 결론 먼저 쓴다.

## 1. 새 논문이 있는지만 먼저 확인한다 (사용량을 아끼기 위해)

다음 명령을 Bash로 실행한다.

```
python -X utf8 -I "<작업 폴더>/.claude/skills/논문요약/scripts/find_new.py" "<작업 폴더>/논문요약"
```

- 아무것도 출력되지 않으면 "새로 추가된 논문이 없습니다." 한 줄만 남기고 **즉시 끝낸다.** 다른 파일을 읽거나 탐색하지 않는다.
- 출력된 줄의 상태가 모두 "이미 요약한 논문의 사본" 또는 "하위 폴더에 있어 처리하지 않음"이면 요약할 논문이 없는 것이다. 사본은 "같은 원본" 파일 이름과 함께 "이미 요약한 논문의 사본이라 건너뛰었습니다. 정리할지 정해 주세요."라고, 하위 폴더 파일은 "01_원본 바로 아래로 옮겨 주세요."라고 알리고 끝낸다. 파일을 지우거나 옮기지 않는다.

## 2. 상태가 "새 논문" 또는 "이름은 바뀌었지만 요약본 없음"인 논문이 있으면 스킬 절차를 따른다

1. 아래 두 파일을 Read로 읽는다.
   - 스킬 절차: `<작업 폴더>\.claude\skills\논문요약\SKILL.md`
   - 사용자 작업 규칙: `<작업 폴더>\CLAUDE.md`
2. SKILL.md의 2~7단계를 해당 논문마다 그대로 수행한다. SKILL.md 안의 `${CLAUDE_SKILL_DIR}`는 `<작업 폴더>/.claude/skills/논문요약`로 바꿔서 실행한다.
3. 사본으로 표시된 파일은 요약하지 않고 보고표에 "건너뜀(이미 요약한 논문의 사본)"으로 적는다.

## 반드시 지킬 것

- 논문에 없는 내용을 지어내지 않는다. 근거가 없으면 "논문에 없음", 확인 못 한 서지정보는 `[확인 필요]`.
- 인용 문장은 원문 그대로 옮기고, verify_quotes.py 검증 실패가 0개가 될 때까지 고친다.
- 파일을 지우지 않는다. 같은 이름의 요약본이 이미 있으면 덮어쓰지 않고 보고에만 적는다.
- 주제 폴더를 만들지 않는다. 원본은 01_원본, 요약본은 02_요약본 바로 아래에 둔다.

## 결과

마지막에 SKILL.md 7단계 형식의 표(논문 | 주제 | 결과 | 확인 필요)와 "완료 N편, 건너뜀 N편, 실패 N편" 한 줄로 보고한다.
