# 논문 요약

졸업논문을 쓰는 사용자가 `01_원본`에 넣은 논문을 정해진 양식으로 요약해, 이론적 배경과 선행연구를 쓸 때 바로 찾아 인용할 수 있게 만든다.

## 절대 규칙

1. **논문에 없는 내용을 추측해서 쓰지 않는다.** 근거 문장을 찾지 못한 항목은 `논문에 없음`이라고 쓴다.
2. **인용 문장은 원문을 한 글자도 바꾸지 않고 그대로 옮긴다.** 문장 중간을 줄일 때만 `…`를 쓴다.
3. **임의로 바꿔 쓰지(paraphrasing) 않는다.** 요약 문장은 바로 아래 붙인 인용 문장이 말하는 범위 안에서만 쓰고, 해석이나 평가를 보태지 않는다.
4. **확인하지 못한 서지정보는 `[확인 필요]`로 둔다.** 저자·연도·권호·쪽·DOI를 지어내지 않는다.
5. 졸업논문 본문을 대신 써 주지 않는다. 요약본만 만든다.
6. 요약본과 보고는 모두 한국어로 쓴다.

## 경로

- 작업 폴더: `<작업 폴더>\논문요약` (아래 `<루트>`)
- 입력: `<루트>\01_원본\*.pdf`
- 출력: `<루트>\02_요약본\(요약본) <파일이름>.md`
- **주제 폴더를 만들지 않는다.** 원본과 요약본은 각각 `01_원본`, `02_요약본` 바로 아래에 둔다. 주제는 요약본 안(맨 위 `주제:` 칸)에만 적는다.
- 제외 폴더: `<루트>\03_제외\` — 요약 대상이 아닌 파일을 옮겨 두는 곳 (아래 "제외 파일" 규칙)
- 작업용 텍스트: `<루트>\.cache\` (옵시디언에 보이지 않는 숨김 폴더)
- 스크립트: `${CLAUDE_SKILL_DIR}\scripts\`. 파이썬은 항상 `python -X utf8 -I`로 실행하고, 경로에 공백이 있으니 따옴표로 감싼다.

## 처리 순서

### 1. 새 논문 찾기

```
python -X utf8 -I "${CLAUDE_SKILL_DIR}/scripts/find_new.py" "<루트>"
```

- 이름이 `(원본)`으로 시작하고 같은 이름의 요약본이 있으면 이미 처리한 논문이라 목록에 나오지 않는다.
- 상태가 "이미 요약한 논문의 사본"인 PDF는 `같은 원본` 칸의 파일과 내용이 완전히 같은 사본이다(md5 비교). 요약하지 않고 보고에 "건너뜀(이미 요약한 논문의 사본, 같은 원본: …)"으로 적는다. 사본을 지우거나 옮기지 않고, 정리할지는 사용자에게 맡긴다.
- 상태가 "하위 폴더에 있어 처리하지 않음"인 PDF는 요약하지 않고, `01_원본` 바로 아래로 옮겨 달라고 사용자에게 알린다. 직접 옮기지 않는다.
- **제외 파일:** 2단계에서 텍스트를 읽어 보니 파일 이름과 실제 내용이 다른 자료(예: 기관 연혁이라는 이름인데 내용은 다른 책)처럼 요약 대상이 아닌 파일이면, 요약하지 않고 이름도 바꾸지 않은 채 `<루트>\03_제외\`로 옮긴다(`mv -n`, 같은 이름이 이미 있으면 옮기지 않고 보고만). 보고 표에 "제외(이유, 실제 내용)"로 적고, 마지막 줄 편수에도 제외 편수를 따로 센다. 지우지 않는다.
- 처리할 논문이 없으면 "새로 추가된 논문이 없습니다"라고 알리고 끝낸다.
- 처리할 논문 수를 먼저 알린 뒤, 한 편씩 2~6단계를 끝까지 마치고 다음 논문으로 넘어간다.

### 2. 쪽별 텍스트 뽑기

```
python -X utf8 -I "${CLAUDE_SKILL_DIR}/scripts/extract_pages.py" "<PDF 경로>" "<루트>/.cache"
```

- 출력된 `.txt`를 Read로 읽는다. 쪽마다 `===== PDF p.N | 인쇄 p.M | OCR =====` 구분선이 있다.
- 글자가 없는 쪽은 스크립트가 Tesseract(한국어·영어)로 OCR한다. 스캔본은 시간이 걸리니 쪽수가 많으면 백그라운드로 실행한다.
- 학위논문처럼 긴 문서는 국문초록·목차·서론·연구방법·결과 요약·결론 부분을 중심으로 읽되, 인용 문장은 반드시 그 쪽에서 직접 옮긴다.

### 3. 서지정보와 쪽 번호 정하기

**쪽 번호는 학술지에 인쇄된 쪽 번호를 쓴다.** (PDF 몇 번째 장인지가 아님)
- 스크립트가 낸 `인쇄쪽보정`(인쇄 쪽 = PDF 쪽 + 보정값)을 첫 쪽의 쪽 범위(예: pp. 129~158)와 대조해 맞는지 확인한다.
- 보정값을 확정할 수 없으면 `(PDF p. N)`으로 표기하고 서지정보에 `쪽 번호: [확인 필요]`를 적는다.

**APA 7판 참고문헌**
- 국내 학술지: `저자1, 저자2. (연도). 제목. 학술지명, 권(호), 시작쪽-끝쪽. https://doi.org/...`
- 영문 학술지: `Author, A. A., & Author, B. B. (Year). Title of article. Journal Name, Volume(Issue), pages. https://doi.org/...` (학술지명과 권은 이탤릭)
- 학위논문: `저자. (연도). 제목 [박사학위논문, 대학교명]. 데이터베이스명.`
- DOI가 없으면 생략하고, 권호·쪽처럼 꼭 필요한 정보를 못 찾으면 `[확인 필요]`.

**본문 인용 표기**

| 저자 수 | 한글 논문 | 영문 논문 |
|---|---|---|
| 1명 | (홍길동, 2020) | (Smith, 2020) |
| 2명 | (홍길동, 김철수, 2020) | (Smith & Jones, 2020) |
| 3명 이상 | (홍길동 외, 2020) | (Smith et al., 2020) |

직접 인용할 때는 쪽을 붙인다: (홍길동, 2020, p. 12)

- 두 주제에 걸치면 논문의 **연구 목적**에 더 가까운 쪽을 고른다. 판단이 어려우면 `기타·분류보류`로 적고 보고에 이유를 적는다.

### 4. 파일 이름 정하기

`저자 (연도). 제목` 형식으로 원본과 요약본에 똑같이 쓴다.
- 저자: 1명 `홍길동` / 2명 `홍길동, 김철수` / 3명 이상 `홍길동 외`, 영문은 성만 써서 `Smith`, `Smith, Jones`, `Smith et al.`
- 제목: 논문 제목 그대로 쓴다. 부제가 있으면 포함한다.
- 윈도우에서 쓸 수 없는 문자: `:` → `_`, `?` → 삭제, `/ \ * " < > |` → 삭제.
- 이름이 150자를 넘으면 부제를 뺀다.
- 저자나 연도를 확인하지 못하면 그 자리에 `[확인 필요]`를 쓴다.
- 예: `(요약본) 이정연 (2019). 외국인 유학생들의 토론 능력 향상을 위한 수업 방안 연구 -'하브루타(Havruta) 설명하기'를 중심으로-.md`

**8번 "내 논문 활용 정리" 작성 규칙**

사용자가 졸업논문의 각 장을 쓸 때 바로 가져다 쓸 원문 문장을 모은다. 칸은 **사용자 논문에서 쓰일 위치**를 기준으로 나눈다(원문에서의 위치가 아님).

| 칸 | 넣을 원문 문장 |
|---|---|
| ① 서론 | 문제 제기, 현황·통계, 연구 공백("연구가 부족하다") 지적 |
| ② 이론적 배경 | 핵심 개념의 정의, 이론·모형 설명, 하위 요인 (저자 자신의 정의·조작적 정의) |
| ③ 선행연구 고찰 | 이 논문이 누구를 대상으로 무엇을 해서 어떤 결과를 얻었는지 보여주는 문장 |
| ④ 연구방법 | 대상, 절차, 프로그램 구성, 측정 도구(척도 이름·문항 수·신뢰도), 분석 방법 |
| ⑤ 논의 | 핵심 결과와 저자의 해석 |
| ⑥ 제한점 및 제언 | 저자가 밝힌 연구의 한계와 후속연구 제언 |

- **요약 문장을 쓰지 않는다.** 원문 문장만 넣고, 문장 끝에 쪽 번호만 붙인다(인용 형식과 검증은 1~7번과 같다).
- **해당하는 문장은 빠짐없이 모두 넣는다.** 1~7번에 이미 쓴 문장이라도 해당하면 넣는다.
- **추출 범위:**
  - 학술지 논문·보고서: 본문 전체에서 뽑는다.
  - 학위논문·단행본: **초록, 서론 장, 결론 장(끝부분의 논의·결론·제언 장 포함)**에서만 뽑는다. 이 경우 8번 제목 아래에 `(초록·서론·결론 장에서 추출)`이라고 적는다.
- **재인용 문장은 넣지 않는다.** 다른 연구를 인용한 문장(괄호 안 저자·연도, "○○(2014)는", "et al." 등이 들어간 문장)은 저자 자신의 연구에 관한 문장이라도 제외한다.
- **한 문장은 가장 잘 맞는 한 칸에만** 넣는다.
- 해당 문장이 하나도 없는 칸은 `논문에 없음`이라고 쓴다.
- 영어 논문은 1~7번과 같이 원문 다음 줄에 `번역(참고)`를 붙인다. 스캔본은 `[OCR · 원문 대조 필요]`를 붙인다.

**항목 작성 규칙**
- 항목마다 근거 인용을 최소 1개 붙인다. 찾지 못하면 그 항목은 `논문에 없음`이라고만 쓴다.
- 인용 줄은 반드시 `> "원문" (p. N)` 형식으로 한 줄에 쓴다. 쪽을 넘어가면 `(pp. 12-13)`, 인쇄 쪽을 모르면 `(PDF p. N)`.
- 쪽이 넘어가는 문장은 쪽 경계에 `…`를 넣는다. 머리말·쪽 번호가 문장 사이에 끼어 있어 그대로 이으면 검증에 실패한다.
- 문장 중간에 각주 번호(예: `Teachers,5`)가 붙어 있으면 그 자리에서 `…`로 끊는다.
- 국문 학위논문은 글자층에 띄어쓰기가 없는 경우가 많다. 인용은 맞춤법에 맞게 띄어 쓰되 글자는 바꾸지 않는다(검증은 띄어쓰기를 무시한다).
- 로마 숫자 쪽(국문초록 등)은 `(PDF p. N)`으로 표기한다.
- **영어 논문:** 요약은 한국어로 쓰고, 인용은 영어 원문 다음 줄에 번역을 붙인다.
  ```
  > "English original sentence." (p. 12)
  >
  > 번역(참고): "한국어 번역"
  ```
- **스캔본(OCR) 쪽에서 가져온 인용:** 줄 끝에 `[OCR · 원문 대조 필요]`를 붙인다. OCR로 빠진 띄어쓰기는 원문 PDF를 보고 맞출 수 있을 때만 맞춘다.
- 요약일은 오늘 날짜로 쓴다.

### 6. 인용 검증 → 원본 이름 바꾸기

```
python -X utf8 -I "${CLAUDE_SKILL_DIR}/scripts/verify_quotes.py" "<요약본.md>" "<루트>/.cache/<PDF 이름>.json"
```

- 실패한 인용이 있으면 `.txt`에서 해당 쪽을 다시 찾아 원문과 쪽 번호를 고친 뒤 다시 검증한다. **실패가 0개가 될 때까지** 다음 단계로 넘어가지 않는다. 끝내 찾지 못한 인용은 지우고, 근거가 하나도 남지 않은 항목은 `논문에 없음`으로 바꾼다.
- 검증을 통과하면 원본 PDF 이름을 `01_원본` 안에서 `(원본) <파일이름>.pdf`로 바꾼다. 같은 이름이 이미 있으면 바꾸지 말고 보고에 적는다.
