# 논문요약 스킬 (Claude Code)

졸업논문 참고논문 PDF를 폴더에 넣으면, Claude Code가 정해진 양식의 요약본(마크다운)을 만들어 주는 스킬입니다.
요약본에 들어가는 인용 문장은 스크립트로 원문 PDF와 대조해 검증합니다.

- 만든 사람: 예인 (AI 부트캠프 3기 챌린지 1)
- 대상 업무: 박사논문을 쓰면서 참고논문을 읽고, 인용할 문장과 쪽수를 정리하는 일

## 무엇을 하나

| 입력 | 출력 |
|---|---|
| `논문요약/01_원본/`에 넣은 논문 PDF | `논문요약/02_요약본/(요약본) 저자 (연도). 제목.md` |

요약본에는 다음 내용이 들어갑니다.

1. 서지정보: APA 7판 참고문헌, 본문 인용 표기
2. 7개 항목 요약: 연구 주제·목적·주요 이론·대상·방법·결과·시사점. 항목마다 원문 인용과 쪽수를 붙입니다.
3. 내 논문 활용 정리: 서론·이론적 배경·선행연구·연구방법·논의·제한점별로 가져다 쓸 원문 문장
4. 확인 필요 항목: 찾지 못한 서지정보 등

처리가 끝나면 원본 PDF 이름이 `(원본) 저자 (연도). 제목.pdf`로 바뀝니다.

## 폴더 구조

```
.claude/skills/논문요약/
├── SKILL.md              # 스킬 절차와 규칙 (Claude가 읽는 파일)
└── scripts/
    ├── find_new.py       # 01_원본에서 아직 요약하지 않은 PDF 찾기
    ├── extract_pages.py  # PDF를 쪽별 텍스트로 추출 (글자 없는 쪽은 OCR)
    └── verify_quotes.py  # 요약본 인용이 표시한 쪽에 실제로 있는지 검증
routine/
└── paper-summary-hourly.md  # 매시간 자동 실행용 루틴 지시문
requirements.txt
```

## 준비물

- Claude Code (데스크톱 앱 Code 탭 또는 CLI)
- Python 3.10 이상, `pip install -r requirements.txt` (PyMuPDF)
- 스캔본 PDF를 처리하려면 Tesseract OCR(한국어·영어 데이터 포함). 설치 경로는 `extract_pages.py`의 `TESSDATA`에 맞춥니다.

## 실행 방법

1. 이 저장소의 `.claude/` 폴더를 작업 폴더(예: `01. 연구`)에 복사합니다.
2. 작업 폴더 안에 `논문요약/01_원본`, `논문요약/02_요약본`, `논문요약/03_제외` 폴더를 만듭니다.
3. `SKILL.md`의 "경로" 절에 있는 작업 폴더 경로를 내 컴퓨터 경로로 바꿉니다.
4. 요약할 PDF를 `01_원본` **바로 아래**에 넣습니다.
5. 그 작업 폴더에서 Claude Code를 열고 `/논문요약`을 입력합니다.

### 자동 실행 (선택)

`routine/paper-summary-hourly.md`의 내용을 Claude 데스크톱 앱의 루틴(예약 작업)에 등록하면, 매시간 새 PDF가 있는지 확인해 요약합니다.
새 PDF가 없으면 스크립트 한 번만 실행하고 바로 끝나서 사용량을 거의 쓰지 않습니다.

## 예외 처리

| 상황 | 동작 |
|---|---|
| 이미 요약한 논문의 사본(이름만 다르고 내용이 같은 PDF) | md5로 비교해 "이미 요약한 논문의 사본"으로 건너뜀. 지우지 않음 |
| `01_원본` 안의 하위 폴더에 넣은 PDF | 처리하지 않고 "01_원본 바로 아래로 옮겨야 함"이라고 알림 |
| 파일 이름과 실제 내용이 다른 PDF | 요약하지 않고 `03_제외`로 옮긴 뒤 보고 |
| 같은 이름의 요약본이 이미 있음 | 덮어쓰지 않고 사용자에게 물음 |
| 인용 검증 실패 | 실패가 0개가 될 때까지 원문을 다시 찾아 고침. 끝내 못 찾은 인용은 삭제 |
| 서지정보를 찾지 못함 | 지어내지 않고 `[확인 필요]`로 표시 |

## 테스트 결과 (2026-10-23)

| 구분 | 입력 | 예상 결과 | 실제 결과 |
|---|---|---|---|
| 정상 | 학술지 논문 1편(7쪽) | 요약본 생성, 인용 검증 실패 0건, 원본 이름 변경 | 요약본 생성, 인용 55개 확인 / 실패 0개, 이름 변경 ✅ |
| 예외 ① | 위 논문의 사본을 `테스트_사본.pdf`로 넣음 | "이미 요약한 논문의 사본"으로 건너뜀 | 같은 원본을 찾아 건너뜀 ✅ |
| 예외 ② | 사본을 `01_원본/테스트_하위폴더/`에 넣음 | "하위 폴더에 있어 처리하지 않음" | 같은 안내 출력, 처리하지 않음 ✅ |

## 한계

- 요약 품질은 Claude의 판단에 기대므로, 인용 문장은 검증되지만 요약 문장의 해석은 사람이 확인해야 합니다.
- 주제는 요약본 안에만 적고, 주제별 폴더 분류는 하지 않습니다.
- 이번 테스트에서는 글자층이 없는 실제 스캔본으로 OCR을 시험하지 않았습니다.
- 수백 쪽짜리 학위논문·단행본은 시간과 사용량이 많이 듭니다.

## 저작권 안내

논문 PDF와 요약본은 저작권 문제로 이 저장소에 포함하지 않았습니다.
